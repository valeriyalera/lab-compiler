# Транслятор підмножини C на Lex/Yacc (flex/bison)

Лабораторна робота з системного програмування.

Синтаксичний аналізатор для C-подібної імперативної мови з побудовою AST,
інтерпретатором, генерацією коду на C та візуалізацією дерева у браузері (d3.js).

## Мова (підмножина C)

- типи `int`, `double`, `void`, оголошення змінних (`int x = 5;`)
- функції з параметрами, `return`, виклики, рекурсія; виконання починається з `main`
- `if / else`, `while`, `for`, блоки `{ }`
- оператори `+ - * / %`, `< > <= >= == !=`, `&& || !`, `++`, `--`
- вбудований `print(expr)`
- коментарі `//` та `/* */`

~~~c
int fact(int n) {
    if (n <= 1) { return 1; }
    return n * fact(n - 1);
}

int main() {
    int i;
    for (i = 1; i <= 5; i++) { print(fact(i)); }
    return 0;
}
~~~

Спрощення: `i++` розгортається в `i = i + 1` у граматиці; область видимості одна на функцію.

## Що зроблено

Робота виконувалась поетапно: від найпростішого калькулятора до повноцінного
транслятора. Після кожного кроку існувала робоча програма.

1. **Лексер і парсер.** Лексер (`lang.l`, Flex) розбиває текст на токени:
   ключові слова, ідентифікатори, цілі та дробові числа, оператори, коментарі.
   Парсер (`lang.y`, Bison) за граматикою перевіряє порядок токенів. Значення
   токенів лексер передає через `yylval`, типи описані в `%union`.
   Пріоритети й асоціативність операторів задані через `%left` і `%right`,
   а проблема dangling else розв'язана парою `%nonassoc IFX` / `%nonassoc ELSE`.
   Граматика не має конфліктів.

2. **Побудова AST.** Дії парсера не обчислюють результат, а створюють вузли
   дерева (`ast.c`). Усі вузли мають один тип `Node` з дітьми `a, b, c, d`
   і полем `next` для списків (оператори, аргументи, параметри, функції).
   Дерево будується знизу вгору в момент згортки правил.

3. **Інтерпретатор (обчислення).** `interp.c` обходить AST двома функціями:
   `eval` обчислює вираз і повертає значення, `exec` виконує оператори.
   Значення зберігає свій тип, тому `7 / 2` дає 3 (цілі), а `7.0 / 2` дає 3.5.
   Кожен виклик функції має власний фрейм змінних, завдяки чому працює рекурсія.
   Оператори `&&` і `||` обчислюються ліниво, як у C.

4. **Генерація коду на C.** `codegen.c` обходить те саме дерево і друкує
   еквівалентну програму на C: спочатку прототипи функцій, потім їх тіла.
   Операції виводяться в дужках, щоб порядок обчислень збігався з деревом.
   Для `print` використано макрос на основі `_Generic` (C11), який сам обирає
   формат `%d` або `%g` за типом виразу. Результат компіляції дає той самий
   вивід, що й інтерпретатор.

5. **Візуалізація AST.** `ast_json.c` виводить дерево у вигляді JS-файлу,
   а `viewer.html` малює його через d3.js: вузли розфарбовані за типом,
   колесо миші масштабує, клік по вузлу згортає гілку.

6. **Розширення до підмножини C.** Додано типи `int` та `double`, оголошення
   змінних, функції з параметрами, `return`, `for`, логічні оператори,
   `%`, `++`, `--` і багаторядкові коментарі.

Схема роботи:

~~~
текст -> [Flex] -> токени -> [Bison] -> AST -> інтерпретатор   (виконання)
                                           -> генератор C      (out.c)
                                           -> експорт JSON     (viewer.html)
~~~

## Режими

| Режим | Команда |
|-------|---------|
| Виконання (інтерпретатор) | `./lang file.lang` |
| Текстове AST | `./lang --tree file.lang` |
| Генерація C | `./lang --c file.lang > out.c` |
| AST для браузера | `./lang --web file.lang > tree.js`, відкрити `viewer.html` |

## Збірка (macOS)

~~~
brew install flex bison
export PATH="$(brew --prefix bison)/bin:$(brew --prefix flex)/bin:$PATH"
cd src && make
~~~

Потрібен bison 3.x (системний 2.3 застарілий).

## Демонстрація

~~~
./demo.sh examples/test3.lang
~~~

Приклади програм лежать у `examples/`. Для `test3.lang` очікуваний вивід:
`1 2 6 24 120 3 3.5 3.5 1 3`.

## Структура

- `src/lang.l` лексер (flex)
- `src/lang.y` граматика і побудова AST (bison), без конфліктів
- `src/ast.c` вузли дерева
- `src/interp.c` інтерпретатор (обчислення, типи, виклики функцій)
- `src/codegen.c` генерація C
- `src/ast_json.c` експорт AST для d3.js
- `src/viewer.html` візуалізація
- `examples/` тестові програми
