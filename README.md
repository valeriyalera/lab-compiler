# Транслятор мини-мови на Lex/Yacc (flex/bison)

Лабораторна робота з системного програмування.

Проєкт: синтаксичний аналізатор для простої імперативної мови з
побудовою AST, інтерпретатором, генерацією коду на C та візуалізацією
дерева у браузері (d3.js).

## Мова

Змінні (числа), присвоєння, арифметика, порівняння, `if/else`, `while`, `print`, блоки `{ }`, коментарі `//`.

## Можливості

| Режим | Команда |
|-------|---------|
| Виконання | `./lang file.lang` |
| Текстове AST | `./lang --tree file.lang` |
| Генерація C | `./lang --c file.lang > out.c` |
| AST для браузера | `./lang --web file.lang > tree.js`, відкрити `viewer.html` |

## Збірка (macOS)

Потрібен bison 3.x (системний 2.3 застарілий).

## Структура

- `src/lang.l` лексер (flex)
- `src/lang.y` граматика і побудова AST (bison)
- `src/ast.c` вузли дерева
- `src/interp.c` інтерпретатор (обчислення)
- `src/codegen.c` генерація C
- `src/ast_json.c` експорт AST для d3.js
- `src/viewer.html` візуалізація
